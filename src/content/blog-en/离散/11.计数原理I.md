Addition Principle, Multiplication Principle, and Pigeonhole Principle.



---

**Definition** : A **set** is an unordered collection of distinct elements. It is usually represented by curly braces. The **cardinality** of a set refers to the number of elements in the set.

**Definition**: A **sequence** is an ordered collection of elements, allowing for repetition. It is usually represented by parentheses.

**Definition:** The **permutation** of a set is a sequence such that every element of the set appears exactly once. The number of permutations of a set with $ n $ elements is $ n!$, there are $ n $ choices for the first position, only $ n-1 $ remain for the second, and so on.

**Definition:** A **function** $ f:X\to Y $ is a relation on $ X,Y $ such that every element in $ X $ is related to exactly one element in $ Y $. $ X $ is called the **domain**, and $ Y $ is called the **range**.

**Definition**: 
**Surjective** means that every element in $ Y $ is mapped to at least once.
**Injective** means that every element in $ Y $ is mapped to at most once.
**Bijective** means that every element in $ Y $ is mapped to exactly once. That is, it is both injective and surjective.

### Mapping Rule

$ f:X\to Y $ is surjective $\implies |X|\ge |Y|$ 
$ f:X\to Y $ is injective $\implies |X|\leq |Y|$
$ f:X\to Y $ is bijective $\implies |X|=|Y|$ (Bijective Rule)

### Generalized Pigeonhole Principle

If $|X|=k|Y|$, then the elements of $\forall f:X\to Y, \exists k+1 $ different $ X $ are mapped to the same element in $ Y $. When $ k=1 $, it is the usual Pigeonhole Principle. It can be proven using proof by contradiction.

Ex. Take any ten two-digit numbers, the subset has $ 2^{10}$ subsets, so there must be at least two subsets with the same sum. Of course, according to the generalized theorem, a higher lower bound can be obtained.

A function $ k-to-1 $ to $ f:X\to Y $ means that every element in $ Y $ is mapped to an element in $ k $ of $ X $, at which point $|X|=k|Y|$. It is also known as the Division Principle.

### Generalized Multiplication Principle

Suppose $ S $ is a sequence of length $ k $, and if there are $ n_1 $ possible first elements, and for each first element there are $ n_2 $ possible second elements... then $|S|=n_1\cdot n_2 \dots \cdot n_k $.

Ex. $ n $ people, choose three people to work on the next three days. There are $ n\cdot (n-1)\cdot (n-2)$ ways. This is common in high school (

Cartesian Product of Sets:

$$
A_1\times ... \times A_n=\{(a_1,...,a_n),a_i\in A_i\}
$$

Multiplication Principle gives:

$$
|A_1\times ... \times A_n|=|A_1|...|A_n|
$$

### Addition Principle

The cardinality of the union of disjoint sets $ A_1,...,A_n $ is the sum of the cardinalities of each set:

$$
|A_1\cup ...\cup A_n|=|A_1|+...+|A_n|
$$
