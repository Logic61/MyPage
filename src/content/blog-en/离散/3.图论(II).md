**Walk** is a sequence of vertices linked by edges, allowing repetition of vertices and edges. The number of edges traversed is $ k $ called the path length.
**Path** does not allow repetition of edges or vertices. $ walk $ .

#### Lemma 1 Path Existence
If there exists a $ walk $ from node $ u $ to $ v $, then there exists a $ path $ from $ u $ to $ v $.

>[!Proof]
>There exists a $ walk $ from $ u $ to $ v $. By the well-ordering principle, there exists a $ walk $ of minimum length. Below, I prove that this is a $ path $.
>If the length equals $ 0,1 $, it is obviously true.
>If the length is $ k \geq 2 $:
>Using proof by contradiction, if it is not $ path $, then there must be repeated vertices. Let $ v_i=v_j $ be such a sequence, then the path $ u=v_0->...->v_i=v_j->...->v=v_k $ is a shorter path (by cutting off the part of $ v_i->v_j $). This leads to a contradiction. Therefore, $ Lemma $ is true.

**Connectivity**: If there is a $ walk $ from $ u $ to $ v $, then they are connected. If every vertex in a graph is connected, the graph is called connected, or a **connected graph**.

**Closed walk** refers to a walk with the same starting and ending point. $ walk $ **Cycle** refers to a walk that does not repeat vertices. $ closed\ \ walk $ .

**Tree**: A connected graph with no cycles.
**Leaf**: A node in a tree $ degree $ that is $ 1 $ the node.

#### Lemma 2 The connected subgraph of a tree is still a tree

>[!Proof]
>Proof by contradiction. Assume the subgraph is connected, but it has a cycle. Then the original graph has a cycle, so it is not a tree, which is a contradiction. Thus, the subgraph has no cycles (this is obvious).

#### Lemma 3 Number of Edges in a Tree
A tree with $ n $ vertices has $ n-1 $ edges.

To prove this, first, we state the existence of leaves.
##### Proof: In any tree with $ n \ge 2 $, there must exist at least two leaf nodes.

**Proof Steps:**

1. **Take the longest path:**
    
In a tree $ T $, since the number of nodes is finite and there are no cycles, there must exist a **longest path** (a path with no repeated vertices), which we denote as $ P = (v_0, v_1, v_2, \dots, v_k)$.
    
2. **Examine the endpoint $ v_0 $:**
    
Consider the nodes connected to the starting point $ v_0 $. Besides the neighbor $ v_1 $ on the path, can $ v_0 $ have any other neighbors?
    
    - **Case A:** If $ v_0 $ is connected to some point $ u $ outside the path, then we can extend the path to $(u, v_0, v_1, \dots, v_k)$. This contradicts the assumption that $ P $ is the “longest path”.
        
    - **Case B:** If $ v_0 $ is connected to an already existing point on the path (for example, $ v_i $, where $ i > 1 $ is in it), since there is already a path between $ v_0 $ and $ v_i $, this new edge will form a **cycle**. This contradicts the definition of a tree having no cycles.
        
3. **Conclusion:**
    
Therefore, $ v_0 $ can only be connected to this single point $ v_1 $. That is, **the degree of $ v_0 $ is $\deg(v_0) = 1 $**.
    
4. **By similar deduction:**
    
The same logic applies to the other endpoint of the path, $ v_k $, and its degree must also be 1.
    

**Result:** The two endpoints of the path $ P $, $ v_0 $ and $ v_k $, are both leaf nodes. Q.E.D.

>[!Proof of Lemma 3]
>By induction.
>It is obviously true for $ n=1,2 $.
>Assume it is true for $ n=k $. For $ n=k+1 $: Remove a leaf, which creates a connected subgraph. According to $ Lemma $ $ 2 $, this is a tree of $ n=k $, so it has $ k-1 $ edges. Adding this leaf only adds one edge, so there are exactly $ k $ edges at this point.

**Spanning Tree (ST)**: A subgraph of a connected graph that is a tree and contains all the vertices. 
A spanning tree is the subgraph with the minimum number of edges that connects all vertices.

#### Theorem Every connected graph has a spanning tree

>[!Proof]
>Assume there is a connected graph $ G $ that has no spanning tree. Let $ T $ be a connected subgraph of $ G $ that has the minimum number of edges among all subgraphs containing all the vertices of $ G $.
>Then, by assumption, $ T $ has a cycle. If we remove one edge from the cycle, the number of edges decreases, but it remains a connected graph. This contradicts the fact that $ T $ has the minimum number of edges, so the original proposition is true.
>
>Proof of remaining connected: Consider any two vertices $ x,y $and the $ walk $ that does not contain the deleted edge $ e $so it will not destroy their connectivity; on the other hand, by the definition of a cycle, besides the edge $ e $ the vertices$ e $ of $ u $ and $ v $ must exist another $ path $  $ P_{uv}$so $ x,y $ there exists a path $(x, \dots, u) + P_{uv} + (v, \dots, y)$ between them, so it is still connected.

**Minimum Spanning Tree (MST)**: For a weighted connected graph, the spanning tree with the minimum total weight.

#### Kruskal's Algorithm (Edge Addition Method)
Each time, select the edge with the minimum weight, as long as it does not form a cycle, until a spanning tree is formed. This becomes the minimum spanning tree.

>[!Lemma]
>$\forall G $, let $ S $ be the set of the first $ m $ edges selected by the algorithm. Then there exists a minimum spanning tree $ T=(V,E)$ such that $ S \in E $.
>
>Proof:
>We use induction. The inductive hypothesis $ P $ is the proposition itself.
>
>When $ m=0 $, $ S $ is the empty set, which is clearly true.
>
>Assume $ P(m)$ holds. Let $ e $ be the edge added at the $ m+1 $ step, and let $ S $ denote the set of the first $ m $ edges selected. By the inductive hypothesis, there exists a minimum spanning tree $ T^*=(V,E^*)$ such that $ S\in E^*$.
>
>If $ e\in E^*$, then it is obviously true,
>Conversely, since $ T^*$ is a spanning tree, the vertices are connected, and adding an edge will form a cycle, which is composed of $ e $ and the path connecting its vertices $ u,v $.
>Since $ S $ is selected without forming a cycle by the algorithm, this cycle must have an edge $ e'$ that does not belong to $ S $. Since the algorithm first selects $ e $ and then selects $ e'$, it can be seen that $ w(e) \leq w(e')$.
>Construct a new tree $ T^{**}$ by deleting $ e'$ from $ T^*$ and adding $ e $. At this point, the graph is still connected and acyclic, so $ T^{**}$ is also a spanning tree, and since $ w(T^{**})=w(T^*)-w(T^{**}) = w(T^*) - w(e') + w(e) \leq w(T^*)$, and because $ T^*$ is already a minimum spanning tree, it can only be equal, so $ T^{**}$ is also a minimum spanning tree. And obviously, this new $ S'\in E^{**}$. is true.
>
>Combining the above, the original proposition is proven by induction.

>[!]
>Let the set of vertices of a connected graph $ G $ be $ V $, with $ n $ vertices. First, we prove that $ n-1 $ edges can be selected.
>According to $ Lemma $, the set of edges of a minimum spanning tree exists and contains $ E $, which has $ S $ edges. Therefore, we can continue to select edges from $ E $ that are not in $ S $. Since $ E $ is the set of edges of a minimum spanning tree, it will obviously generate a subgraph without cycles until there are $ n-1 $ edges.
>.
>After selection, there are $ S\in E $, and their number of elements is equal, so $ S=E $, which means the algorithm has generated a minimum spanning tree.
