**A well-ordered set** is a set where every element can be compared in size, and every subset has a smallest element. **Well-Ordering Principle (WOP)**: Any set of natural numbers contains a smallest element.

# Proof by contradiction
#### 1. After verifying the boundaries, consider the set $ C $ containing $ n $ that does not satisfy the proposition.## 2. Using the Well-Ordering Principle, there exists a smallest element $ m $ 

#### 3. Using the proposition, obtain a smaller element or a contradiction

# Example
### Sum of consecutive natural numbers

$$
1+2+...+n=\frac{n(n+1)}{2}
$$

It is obvious that it holds for $ n=1 $. Assume the set $ C $ contains all $ n $ that do not satisfy the above. Assume $ C $ is non-empty, by $ WOP $, $ C $ has a smallest element $ m>1 $. Then for all $ x<m $, the proposition holds, so there exists $ m-1 $ that satisfies the proposition, so

$$
1+2+...+m - 1=\frac{(m-1)m}{2}
$$

adding $ m $ to both sides gives that the proposition also holds for $ m $, a contradiction, so $ C $ is actually the empty set, and the proposition holds.
### Every positive rational number can be written as a reduced fraction
Prove that any positive rational number $ q $ can be written as a reduced fraction (i.e., $ q = \frac{m}{n}$, and $\gcd(m, n) = 1 $). We can do this:

1. **Constructing the set of integers:**
    
Let $ S $ be the set of positive integers that can be the denominator of $ q $.

$$
S = \{ n \in \mathbb{Z}^+ \mid \exists m \in \mathbb{Z}^+, q = \frac{m}{n} \}
$$

2. **Applying the Well-Ordering Principle:**
    
Since $ q $ is a rational number, $ S $ must be non-empty. By the **Well-Ordering Principle for positive integers**, there must exist a **smallest positive integer** in $ S $, which we denote as $ n_0 $.
    
3. **Corresponding numerator:**
    
Since $ n_0 \in S $, there must exist a corresponding positive integer $ m_0 $ such that $ q = \frac{m_0}{n_0}$.
    
4. **Proof of reduced form (by contradiction):**
    
Assume $\gcd(m_0, n_0) = d > 1 $.
    
Then we can divide both sides by $ d $, getting $ m' = \frac{m_0}{d}$ and $ n' = \frac{n_0}{d}$.
    
At this point, $ q = \frac{m'}{n'}$, and $ n'$ is also a positive integer.
    
Since $ d > 1 $, it is obvious that **$ n' < n_0 $**.
    
5. **Deriving a contradiction:**
    
This shows that $ n'$ should also be in the set $ S $, but we previously assumed that $ n_0 $ was the smallest element in $ S $. This is a contradiction!
    
Therefore, the initial assumption $\gcd(m_0, n_0) > 1 $ is false, meaning $ q = \frac{m_0}{n_0}$ is already a reduced fraction.
### The equation has no positive integer solutions

$$
4a^3+2b^3=c^3 \text{no positive integer solutions}.
$$

Let the set $ S = \{a \in \mathbb{Z}^+ \mid \exists b, c \in \mathbb{Z}^+, 4a^3 + 2b^3 = c^3\}$. By the **Well-Ordering Principle**, since $ S $ is a non-empty subset of the positive integers, it must contain a **smallest element**, denoted as $ a_0 $. The corresponding solution is denoted as $(a_0, b_0, c_0)$.
Observe the equation:

$$
4a_0^3 + 2b_0^3 = c_0^3
$$

- **Step 1: Regarding $ c_0 $**
    
The left side $ 4a_0^3 $ and $ 2b_0^3 $ are both even, so $ c_0^3 $ must be even.
    
This means that $ c_0 $ itself must be even. Let $ c_0 = 2C $, where $ C \in \mathbb{Z}^+$.
    
Substitute into the original equation: $ 4a_0^3 + 2b_0^3 = (2C)^3 = 8C^3 $.
    
Divide both sides by 2, getting: **$ 2a_0^3 + b_0^3 = 4C^3 $**.
    
- **Step 2: Regarding $ b_0 $**
    
In the new equation, $ 2a_0^3 $ and $ 4C^3 $ are both even, so $ b_0^3 $ must be even.
    
This means that $ b_0 $ is even. Let $ b_0 = 2B $, where $ B \in \mathbb{Z}^+$.
    
Substitute into the equation: $ 2a_0^3 + (2B)^3 = 4C^3 \Rightarrow 2a_0^3 + 8B^3 = 4C^3 $.
    
Divide both sides by 2, getting: **$ a_0^3 + 4B^3 = 2C^3 $**.
    
- **Step 3: Regarding $ a_0 $**
    
Now, $ 4B^3 $ and $ 2C^3 $ are both even, so $ a_0^3 $ must be even.
    
This means that $ a_0 $ is even. Let $ a_0 = 2A $, where $ A \in \mathbb{Z}^+$.
    
Substitute to get: $(2A)^3 + 4B^3 = 2C^3 \Rightarrow 8A^3 + 4B^3 = 2C^3 $.
    
Divide both sides by 2 one last time, getting: **$ 4A^3 + 2B^3 = C^3 $**.
    

---

**Deriving a contradiction**:

Observe the last obtained equation $ 4A^3 + 2B^3 = C^3 $, which shows that $(A, B, C)$ is also a set of positive integer solutions to this equation.

This means that $ A \in S $.

However, according to the construction above, $ a_0 = 2A $, since $ A $ is a positive integer, it is obvious that:

$$
A < a_0
$$

This directly contradicts our initial assumption—that **$ a_0 $ is the smallest element in the set $ S $**.

**Conclusion**

Since assuming the existence of a solution leads to a logical contradiction (one can always find a smaller solution), by proof by contradiction, the equation has **no solution** in the positive integers.

In fact, we can see that this result can be generalized; it works even with more unknown variables, for example,

$$
8w^3 + 4x^3 + 2y^3 = z^3
$$

and can also be proven to have no solution in the same way. By extension, we have:

$$
2^nx_n^3+...+2x_1^3=y^3
$$

No solution, which can also be proven similarly. Of course, this is not limited to $ 2 $; it can be generalized to prime numbers $ p $ and any power:

$$
p^{n-1}x_{n-1}^d + p^{n-2}x_{n-2}^d + \dots + px_1^d = x_0^d
$$

and can also be proven in a completely similar manner.

### Inequalities of discrete values

$$
n\leq 3^{n/3}
$$

hold for positive integers. First, for $ n\leq 4 $, it is obvious. Let $ C $ be the non-empty set of positive integers that do not satisfy the inequality. By $ WOP $, this set has a minimum element $ m\ge 5 $. Then we have $ m-1 \le 3^{(m-1)/3}$, and multiplying both sides by $ 3^{1/3}$ gives:

$$
3^{1/3}(m-1)\le 3^{m/3}
$$

Then it is sufficient to show that $ 3^{1/3}(m-1) \ge m $ leads to a contradiction, rearranging the terms to get:

$$
m\ge \frac{3^{1/3}}{3^{1/3}-1}
$$

Calculating the right side gives $ 3.26 $, which clearly satisfies the value of $ m $, thus $ m\le 3^{1/3}(m-1)\le 3^{m/3}$ is a contradiction, so the original inequality holds.

### A finite non-empty set of real numbers has a minimum element
We need a clever transformation because the Well-Ordering Principle is usually defined for **natural numbers** ($ 0, 1, 2, \dots $).

**Step 1: Proof by Contradiction Assumption**

Assume there exists a finite non-empty set of real numbers that **does not** have a minimum element.

**Step 2: Constructing a Set of Natural Numbers**

We form a set $ C $ consisting of the **cardinalities (number of elements)** of all finite sets of real numbers that 'do not have a minimum element'.

$$
C = \{ n \in \mathbb{Z}^+ \mid \text{a size of } n \text{ the set of real numbers has no smallest element} \}
$$

**Step 3: Applying the Well-Ordering Principle**

According to our assumption, $ C $ is a non-empty set of natural numbers. By the **Well-Ordering Principle**, $ C $ must have a minimum element, which we call $ k $.

This means:

- There exists a set of real numbers $ S = \{a_1, a_2, \dots, a_k\}$ with cardinality $ k $ that does not have a minimum element.
    
- Any non-empty set of real numbers with a cardinality smaller than $ k $ **must** have a minimum element (because $ k $ is the smallest in $ C $).
    

**Step 4: Finding the Contradiction**

- Clearly, $ k > 1 $, because a set with only one element $\{a_1\}$ has itself as its minimum element.
    
- Consider the set $ S $. We can split it into two subsets: $ S' = \{a_1, \dots, a_{k-1}\}$ and $\{a_k\}$.
    
- Because the cardinality of $ S'$ is $ k-1 $, which is less than $ k $, by definition, $ S'$ **must have a minimum element**, let's call it $ m'$.
    
- Now, the minimum element of the entire set $ S $ only needs to be compared between $ m'$ and $ a_k $:
    
    - If $ m' \le a_k $, then $ m'$ is the minimum element of $ S $.
        
    - If $ a_k < m'$, then $ a_k $ is the minimum element of $ S $.
        
- In either case, $ S $ has a minimum element.
    

**Conclusion:**

This contradicts the assumption that '$ S $ does not have a minimum element'. Therefore, our assumption is false, and all finite non-empty sets of real numbers must possess a minimum element.

**Although real numbers themselves are not well-ordered (for example, the open interval $(0, 1)$ has no minimum), the 'size' (number of elements) of a set is a natural number and is subject to the Well-Ordering Principle.** We proved the conclusion by mathematical induction (or well-ordering analysis) on the set's size.
