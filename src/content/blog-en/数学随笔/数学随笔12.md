If a legal operation does not change a certain variable of the system, then if the invariant of the initial state and the final state are different, it can be asserted that the final state is unreachable.



# 3×3 Huarong Dao Unreachability Proof

> [!ABSTRACT] Proposition
> In the grid $ 3 \times 3 $, with an initial arrangement of `abcdefgh` (space at the end), it is impossible to transform it into `abcdefhg` (space at the end) using the legal Rush Hour/sliding puzzle rules.

## 2. Mathematical Proof: Inversions and Parity

### 2.1 Definition of Inversions
For a permutation, if a pair of elements $(x, y)$ satisfies that $ x $ appears before $ y $ but $ x > y $, it is called an **inversion pair**.

* **Sequence of State A:** $(a, b, c, d, e, f, g, h)$
    * Number of Inversions: $ N(A) = 0 $ (**Even Permutation**)
* **Sequence of State B:** $(a, b, c, d, e, f, h, g)$* Inversions: Only $(h, g)$ pair, because the letters are in order $ h > g $.
    * Number of Inversions: $ N(B) = 1 $ (**Odd Permutation**)

### 2.2 Parity Transformation of Movement Rules

#### When performing a row move, the number of inversions of the permutation does not change.

proof: Obvious

#### When performing a column move, the parity of the number of inversions remains unchanged.

proof: By numbering from left to right and top to bottom, a column move changes the numbering by 3, exactly skipping over two letters. Enumeration shows that this changes the number of inversions by +2, -2, or 0, so its parity remains unchanged, thus the parity of the number of inversions is invariant.

#### Therefore, the number of inversions is an invariant.

### 2.3 Completing the Proof

The number of inversions for the two states are 0 and 1, which have different parities, so they cannot reach each other.

Rigorously, mathematical induction can be used. Assume that $ n $ steps have been performed, and it has been proven that one step does not change the parity. Below, assume the parity remains unchanged after $ n=k-1 $ steps. Taking one more step, by the same logic, the parity remains unchanged, and thus the parity at $ n=k $ is the same as the initial state. Therefore, by the principle of mathematical induction, the parity is an invariant.
