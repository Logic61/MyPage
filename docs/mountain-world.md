# 山中书斋：3D 探索原型

这一分支把中英文首页接入一个连续的 Three.js 山居场景。前庭、洞内书斋与东侧观景回廊共用同一世界坐标；真实文章、项目与简历仍由现有 Astro 页面生成。

## 使用

- WASD / 方向键移动；按住 Shift 可快走。
- 点击地面自动沿可走路线移动；点击可见物件会先走近再交互。
- 拖动画面转动镜头，滚轮小幅缩放；R 或右上角按钮恢复镜头。
- 靠近物件后按 E，或点击提示。书架打开文章目录，案头手记显示最近文章，工作案打开项目，信笺打开简历。
- 庭院纸灯可以开关；观景长凳可以坐下，移动时起身。
- 右上目录及右下山居小引可搜索文章或选择前往地点。
- Esc 合上阅读层，角色与镜头留在原处。离开页面后，本次会话会记住角色位置。
- 环境声音默认关闭，主动开启后才创建音频。

## 实现位置

- `src/components/MountainWorld.astro`：真实文章元数据与界面。
- `src/scripts/mountain-world/main.ts`：渲染、输入、镜头、拾取、会话与音频。
- `environment.ts`：程序生成的地台、洞府、道路、植物、远山与碰撞。
- `furnishings.ts`：书册、案台、灯、长凳、题辞与物件交互。
- `traveller.ts`：访客模型、步行与坐姿。
- `navigation.ts`：圆形角色碰撞、静态网格寻路、路径平滑。
- `ui.ts`：目录与同源正文读取、请求取消、焦点与兼容界面。

3D 资源由代码与本地 Canvas 纹理生成，不依赖第三方模型 CDN。静态景物使用实例或合并网格，墙顶在访客进入书斋时自动淡出；射线拾取尊重不透明环境遮挡。

当前可走部分位于同一山腰台地，角色地面高度为 `y = 0.3`。向山下延伸的阶梯与远山属于景观。需要增加高差探索时，应同时扩展地面高度查询与导航，避免只改变可见网格。

## 开发与验证

需要 Node.js 22.12 或更新版本。

```sh
npm ci
npm run dev
npm run check:world
npm run test:world
npm run build
```

导航测试覆盖绕障、圆形角色与地图边缘的间隙、长步长穿墙、门洞连通及不可达目标。场景整合还检查六处交互的可达性、室内外屋顶状态、几何共面与实体遮挡。

WebGL 不可用时，界面显示原有山景以及真实文章、项目、简历入口，目录仍可阅读。测试环境当前禁用 WebGL，因此完整实时画面、设备帧率与触屏移动仍需在支持 WebGL2 的浏览器中验收；离线几何渲染仅用于检查构图、比例与遮挡，不等同于浏览器试玩。
