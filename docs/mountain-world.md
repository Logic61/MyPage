# 云庭书斋：第一人称山居

中英文首页共用一座可步行的云上书院。从南侧石桥进入，山门、方荷池、北厅匾额、主案和山水圆屏排列在 `x=0` 中轴上。两翼、外廊与六角亭按轴对称，东亭临崖设观景长凳，西亭摆石棋案。

## 空间与材质

### 石桥与轴线庭院

以世界坐标的负 Z 方向为北。先在南侧候云台望见主堂的重檐和脊上日轮，再沿渡云桥穿过低门楼。入庭便见居中的方荷池，两条石径沿东西池岸绕行，在北堂阶前重新汇合。东亭外另有一跨云栈，走到日轮台，铜环中央露出远山。[建筑透视与总平面概念图](design/cloud-pass-study.webp)

分景图将九处空间分别展开，展示它们的进深、轮廓和近看的构件。[九景四视图与浏览器实景](design/cloud-court/README.md)

设计时参考了《古剑奇谭三》把建筑设定与实景模型对应展示的方法，以及中国园林从建筑开口借取远景的组织方式。[鄢陵设定与模型](https://gjqt3.wangyuan.com/2018/03/13/000003.shtml) · [华盛顿大学中国园林建筑图例](https://depts.washington.edu/chinaciv/home/tgararch.htm)

### 材质分工

| 材质 | 主要用途与设计约束 |
| --- | --- |
| 白灰泥 | 墙体和室内背景，承接天光与窗影，保持大面的安静和明亮 |
| 浅木 | 室内地板、廊面、窗洞内侧及檐下顶面，保持明亮且能读出板材铺向 |
| 深木 | 梁柱、稀疏格栅、主案和藏书架，交代构造与人体尺度，衬托白墙和画面 |
| 净石 | 通行地面、门槛、池沿和台地基座，以清楚的块面与接缝组织路径 |
| 深青屋面 | 筒瓦分垄搭接，烧制纹理和粗糙度调节瓦光。每坡的瓦当和椽头成行居中 |
| 纸、绢、布、黄铜与陶瓷 | 服务书籍、圆屏、灯具、器物和软垫的近看细节 |

材质的颜色、粗糙度、法线和纹理尺度各有职责。白墙不铺满碎石噪声，浅木不与深青屋面混成一整片暗色；水庭和天井保留开敞的天光，圆屏仍是可阅读的画面。

## 使用

- 点击「走进云庭」开始。`W A S D` 行走，按住 `Shift` 奔跑，方向键转动视线。
- 桌面锁鼠成功后，系统光标隐藏，移动鼠标环顾；用中心准心瞄准物件，按 `E` 或左键交互。
- 脱锁后单击场景即可重新锁定。暂停时也可以直接点击露出的画面继续。浏览器拒绝锁定时可拖动环顾，也可将鼠标移向画面边缘持续转向。移回中央或移出画面即停止，点击空处可重试锁定。
- 博客、项目、简历三枚金墨路标随视线移动，离开画面后在边缘提示方向。用触屏或自由鼠标点路标可打开对应内容，锁鼠时用准心对准路标按 `E`。近处直接瞄准物件优先。
- 藏书架打开文章目录，书案上的「近作」显示最近八篇文章，工作案打开「项目」，北厅东壁的「简历」挂轴展开履历。阅读器采用子午观象台的原版双木轴与旧纸。宽屏并排显示书目与正文，手机用「选篇」切换。翻篇、切换卷页或合卷再开都可接续阅读。
- 两盏池灯可分别开关。坐上东亭长凳时沿用行走时的鼠标锁定，可继续转头观景。点击「起身」、按 `E` 或使用行走键回到原站位。坐姿下解锁鼠标可继续观景。
- `Esc` 暂停并释放鼠标，`M` 打开目录。合上阅读框后，点击「继续探索」恢复控制。
- 目录地点按钮沿可走路线引导至物件；有效的手动环顾或行走会中止引导。右上回转按钮返回庭门。
- 触屏使用左侧摇杆行走、右侧拖动环顾，看向物件后轻触提示。当前输入按实际指针类型切换，触屏设备接鼠标也能使用鼠标模式。
- 暂停页的「静态页面」打开漫游版之前的纸墨书架首页，中英文分别在 `/MyPage/static/` 和 `/MyPage/en/static/`。暂停页还可选择画面档位、灵敏度和行走起伏。起伏默认关闭，并遵守系统减少动态效果的偏好。
- 环境声默认关闭，主动开启后才创建音频；页面隐藏时静音。

### 瞄准与输入合同

实际 `document.pointerLockElement` 决定是否锁鼠；页面处于探索状态不代表锁鼠成功。

| `data-input-mode` | 可见反馈与交互目标 |
| --- | --- |
| `locked` | 系统光标隐藏，中心准心与中心射线一致 |
| `pointer` | 保留系统鼠标，不显示中心准心；按画布 CSS 范围换算鼠标射线，物件提示跟随鼠标 |
| `drag` | 累计手势达到拖动阈值后，暂时隐藏鼠标并使用中心准心；松开不触发点击 |
| `touch` | 使用中心瞄准及触屏交互提示 |
| `pending` / `none` | 不进行物件瞄准或交互 |

鼠标离开画布时清空悬停目标。拖动从按下位置累计判断，连续小位移或拖回起点都不能被误当作点击。拾取先取得可交互物件的精确命中，再检查目标前的实体遮挡和距离，不能隔墙触发。

鼠标位移累积为目标角度，动画帧按 12 毫秒时间常数平滑显示朝向。暂停、阅读或失锁时清掉尚未显示的旧输入。拖动到画面边缘后松手，视角会停下，再次移动鼠标才会启动边缘环顾。导航抵达和普通模式下坐下时沿最短弧转向，手动输入可以立即接管。坐下与起身约用 300 毫秒移动到位。启用系统「减少动态效果」时，坐下保留原来的朝向，坐下与起身的位置过渡缩短至 150 毫秒。

点击「走进云庭」和恢复漫游共用同一个锁鼠控制器，优先请求 `unadjustedMovement`。浏览器明确返回 `NotSupportedError` 时尝试一次普通锁定，其他失败进入自由指针模式。Promise 接口按拒绝原因分类，旧版接口等待锁定事件。新的进入操作可以承接仍待决的请求，避免排队多个原生请求。实现与兼容说明见 `pointer-lock.ts` 和 [MDN Pointer Lock API](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_Lock_API)。

## 加载、渲染与释放

环境的可走面、collider、交互物件和背景 fallback 几何同步创建。图片的异步就绪只替换贴图，不能在导航或拾取器建立之后悄悄增加新的关键结构。

建筑饰面、松针、画作的 `assetsReady` 与背景的 `ready` 共用一次 **1500 ms** 有界等待。全部完成则提前编译场景；失败或超时后，圆屏的 Canvas 山水和背景的同步几何与渐变天空允许继续进入。迟到的图片仍可以正常替换，已经释放的场景则丢弃并释放迟到纹理。

从 renderer 创建起便注册幂等 `teardown`，覆盖初始 RAF、字体、图片和编译阶段。退出时清理等待 timer、结束当前初始化等待并释放已创建资源；等待结束后先检查页面和资源状态，再启动编译。编译过程中离开，后续结果不会再次渲染或启用界面。图形上下文丢失也终止初始化并显示真实阅读入口。BFCache 暂存走暂停与恢复流程，保留当前文档所需的资源。

背景必须先于渲染管线创建，其根节点带有 `ignoreAmbientOcclusion` 标记。AO 通道临时隐藏整棵背景与粒子、线条等排除对象，并通过 `finally` 恢复原有可见性。后处理抛错时，先恢复临时覆盖材质、自动清屏开关、清屏颜色与透明度，再切回直接渲染，避免把法线通道的状态带入正常画面。

新增可选图片时，应接入现有共同等待和清理队列，并提供同步 fallback。若异步加载的是建筑或关键碰撞结构，则必须先完成结构加载再创建导航与拾取器，不能直接沿用装饰图片的超时放行方式。

## 坐标、导航与状态恢复

院坪标高为 `y=0.3`，站立眼高为地面以上 `1.68 m`。北堂四级石阶共升高 `0.64 m`，从正面和两侧拾级而上时，视线沿踏步坡度平稳升高。堂内的桌案、壁灯、挂轴、简历交互点和地板落在同一层台基上。

`sitPosition` 表示实际座面接触点，相机另加 `.8 m`。家具调整位置或朝向时，必须同步更新 mesh、物件瞄准中心、`approach`、collider 和坐姿数据。六种交互为书架、手记、作品、自序、池灯、长凳。东西池灯分别使用 `east-lantern` 和 `lantern`，同一枚庭灯路标指向近侧。

当前入口为 `(x=0,z=34)`，`#study` 返回落点为 `(0,-4.6)`。出生点与候选落点都要通过 `canWalk` 验证；没有安全出生点时显示阅读回退，不把人物放到未经检查的旧坐标。`#study` 是独立文章页「回到书斋」的公开链接，应在改版时继续支持。

会话位置键为 `mountain-first-person-v5-cloud-pass:${base}`。中英文共享同一布局位置；有效存档优先于 `#study`，恢复前检查可站立性。存档记录站位与视线，坐下时保存原站位。重大布局变更应升级地图版本，避免把旧坐标和旧朝向沿用到新建筑；画面质量与灵敏度偏好独立保存。

改布局的最小同步范围是：入口与返回落点、区域名称与室内判断、可走面和障碍、各处交互及坐姿、灯光位置和阴影范围、真实场景 QA 机位。`findPath()` 会调整不安全的目标点，因此验收时还必须单独确认每个原始 `approach` 可站立。

### 从长凳与鼠标输入复核镜头
